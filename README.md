# PURE.GLOW 💄✨

### Premium Beauty & Bridal Booking Website

PURE.GLOW is a modern and elegant beauty and bridal website designed to showcase professional beauty services, bridal packages, portfolios, and appointment booking options.

The project focuses on a premium visual experience combined with interactive JavaScript features for beauty service selection and package estimation.

---

## 🌟 Features

* 💄 Premium Beauty & Bridal Design
* 👰 Bridal Makeup Services
* 💇 Hair Services
* 💅 Nail Services
* 🧖 Skin Care Services
* 🌿 Mehndi Services
* 📸 Beauty Portfolio / Gallery
* 🖼️ Before & After Slider
* ✨ Interactive Beauty Recommendation
* 🧮 Package Price Estimator
* 💰 Service & Package Pricing
* 📅 Bridal Date Reservation
* 📋 Appointment Booking
* 💬 WhatsApp Booking
* ⭐ Customer Testimonials
* ❓ FAQ Section
* 📱 Responsive Design
* ✨ Smooth Animations
